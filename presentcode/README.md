# PresentCode - Presentation Editor

An ultra-sleek, lightweight, PowerPoint-inspired presentation editor built with **Pure HTML, CSS, and Vanilla JavaScript** — zero build step, no dependencies, runs natively in any browser!

---

## 🚀 Live Demo & Usage
Simply open `index.html` directly in any web browser (Chrome, Edge, Firefox, Safari) or serve with any simple static server.

---

## ✨ Features

- **PowerPoint Inspired Ribbon Interface**:
  - File, Home, Insert, Slides, Draw, Design, Transitions, Animations, Slide Show, and View.
- **50+ Google Fonts**:
  - Sans-Serif, Serif, Display, Handwriting, and Monospace families loaded on demand.
- **30+ Object Keyframe Animations**:
  - Entrance (Fade In, Bounce In, Flip, Zoom, Rotate, Light Speed, etc.)
  - Emphasis (Pulse, Heartbeat, Shake, Tada, Wobble, Jello, Rubber Band, Flash)
  - Exit (Fade Out, Zoom Out, Bounce Out, Flip Out, Roll Out, Hinge Fall)
- **17 Slide Transitions**:
  - Fade, Push Left/Right/Up/Down, Wipe, Zoom, 3D Flips, Circle Reveal, Diamond Mask, Split Doors, Swirl.
- **Interactive Canvas**:
  - Move, resize (8 handles), and rotate elements.
  - "Click to add title" & "Click to add subtitle" placeholders.
  - Rectangles, Rounded Rectangles, Circles, Triangles, Stars, Arrows.
  - Image upload from computer or web URL.
- **Drawing Mode**:
  - Freehand Pen, Highlighter, and Eraser with color and stroke width controls.
- **Slide Deck Management**:
  - Add Slide, Duplicate, Delete, Reorder, Background color presets & custom pickers.
- **Fullscreen Presentation Mode (F5)**:
  - 16:9 widescreen stage with keyboard shortcuts (Arrow keys, Space).
  - Presenter Laser Pointer tool (Press 'L').
  - Black Screen toggle (Press 'B').
- **Export & Portability**:
  - Save / Load `.present` JSON file format.
  - Export complete **Self-Contained Standalone HTML Presentation** (open anywhere without internet!).
  - Print / Save to PDF.
